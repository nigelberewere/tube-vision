# Script Structures Reference

Use this file to select the right structure before writing. Match by format first, then by length.

---

## 1. Narrative / Documentary / History (most common for educational channels)

### Short (3–6 min) — ~600–900 spoken words
| Section | Timecode | Notes |
|---|---|---|
| Hook | 0:00–0:30 | One line. One fact. No context yet. |
| Setup | 0:30–1:30 | Who, what, when — in under 90 seconds |
| Revelation | 1:30–4:00 | The buried angle. One strong pivot. |
| Reckoning | 4:00–5:30 | Consequence + what it means today |
| CTA | 5:30–6:00 | One ask |

### Mid (8–14 min) — ~1,600–2,200 spoken words
Standard Twisted Hour / documentary structure. See SKILL.md Step 2.

### Long (16–22 min) — ~3,000–4,000 spoken words
Add a second act pivot and an extended aftermath. Structure:
- Hook (0:00–1:00)
- Context (1:00–3:30)
- Act 1: Escalation (3:30–7:00)
- Act 2: The hidden layer (7:00–12:00)
- **Mid-video re-hook** (12:00–12:30) — mandatory at this length to prevent drop-off
- Act 3: Consequences (12:30–17:00)
- Act 4: Reckoning + modern relevance (17:00–20:00)
- CTA (20:00–20:30)

## 2. Listicle ("Top X", "X Things You Didn't Know", "X Mistakes")

### Mid (8–12 min)
| Section | Timecode | Notes |
|---|---|---|
| Hook | 0:00–0:45 | Tease the most surprising item without naming it |
| Setup | 0:45–1:30 | Why this list matters. One sentence thesis. |
| Items 1–3 | 1:30–5:00 | Build in intensity. Never save the best for last if you want retention. Put #2 or #3 as the strongest. |
| Re-hook | 5:00–5:20 | "And we haven't even gotten to the one that actually..." |
| Items 4–X | 5:20–10:30 | Continue escalating |
| Wrap | 10:30–11:30 | Callback to the hook. What this all means. |
| CTA | 11:30–12:00 | Comment prompt: "Which one surprised you most?" |

**Key rule:** The best item goes at position 2 or 3, not last. Retention drops after the 60% mark — don't bury your strongest content.

## 3. Essay / Commentary / Opinion

### Mid (8–14 min)
| Section | Timecode | Notes |
|---|---|---|
| Cold take | 0:00–0:45 | State your position immediately. Controversy → curiosity. |
| Steel-man | 0:45–2:30 | Give the opposing view its strongest form. This builds trust. |
| Rebuttal | 2:30–6:00 | Dismantle the steel-man with evidence, not dismissal |
| The nuance | 6:00–9:00 | What's true on both sides. Where you actually land. |
| So what | 9:00–11:30 | Why this matters beyond the debate |
| CTA | 11:30–12:00 | Comment: "Where do you land on this?" |

**Key rule:** Never open with "So today I want to talk about...". Open with the take.

## 4. True Crime / Mystery

### Mid (10–16 min)
| Section | Timecode | Notes |
|---|---|---|
| Crime/mystery reveal | 0:00–1:00 | The outcome first. Then pull back to the beginning. |
| Before | 1:00–3:30 | Who the people were before. Make the viewer care. |
| The event | 3:30–7:00 | What happened. Slow and detailed — this is the core. |
| Investigation | 7:00–11:00 | The chase. False leads. Twists. |
| Resolution (or lack of) | 11:00–14:00 | What we know. What we don't. Why it still matters. |
| CTA | 14:00–14:30 | "What do you think happened?" |

**Key rule:** Unresolved cases perform better than solved ones because the comment section becomes an extension of the investigation.

## 5. Finance / Self-improvement / How-to

### Mid (8–12 min)
| Section | Timecode | Notes |
|---|---|---|
| Pain hook | 0:00–0:45 | Name the problem the viewer already has |
| Cost of inaction | 0:45–2:00 | What happens if they keep doing what they're doing |
| The framework | 2:00–8:00 | The actual teaching. 3–5 steps. Show, don't just tell. |
| Common mistakes | 8:00–10:00 | What people get wrong. This is highly shareable. |
| Quick win | 10:00–11:00 | Something they can do in the next 24 hours |
| CTA | 11:00–11:30 | Subscribe = more frameworks like this |

**Key rule:** Hook on the pain, not the solution. "You're losing money every month you do this" → far stronger than "Here's how to save money".

## 6. YouTube Shorts (under 60 seconds)

~120–150 spoken words maximum.

Structure:
1. **Hook** (0–3 sec): One visual + one line. Must work without sound.
2. **Delivery** (3–45 sec): One idea. One revelation. No detours.
3. **Punchline or pivot** (45–55 sec): The payoff or the twist.
4. **Loop trigger** (55–60 sec): End in a way that makes rewatching feel natural — a question, a visual callback, or an unresolved beat.

**Key rule:** Shorts are rewatched, not subscribed from. The goal is loops, not CTAs.
